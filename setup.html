Step 4 of the README

Initialize the operation

This creates one login per agent, writes the roster, starts the clock, and generates each agent's private link. Run it once. Links are shown only on this screen, so save them before leaving.

Firebase isn't configured. Fill in js/config.js first.

Agent links

Send each agent only their own link by private message, plus the passphrase (ideally through a different channel). Anyone with a link and the passphrase can act as that agent.

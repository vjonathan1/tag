Step 4 of the README

Initialize the operation

This creates one login per agent with the password you set below, writes the roster, and starts the clock. Run it once. Everyone uses the same site link and signs in by picking their name and typing their password.

Firebase isn't configured. Fill in js/config.js first.

Agent passwords

At least 6 characters each, all different. Players can change theirs later from the app.

Send to each agent

Send each agent only their own message, privately. The site link is the same for everyone; the password is what proves who they are. Passwords aren't stored anywhere you can read later, so save this list now.
